# เวอร์ชันอ้างอิง

PLAN.md §6 กำหนดให้เทียบพฤติกรรมกับ GNU เวอร์ชันที่ Ubuntu LTS ล่าสุดใช้ และล็อกเวอร์ชันไว้ที่นี่

## ที่ใช้อยู่ตอนนี้ (M0)

| ชุดเครื่องมือ | เวอร์ชัน | หมายเหตุ |
|---|---|---|
| GNU coreutils | 9.4 | ตรวจจาก `/usr/bin/echo --version` ใน environment พัฒนา และ CI ตรึง runner เป็น `ubuntu-24.04` ซึ่งใช้ 9.4 เช่นกัน |

golden test (`tests/golden/`) ตรวจว่าเครื่องมืออ้างอิงเป็น "GNU coreutils" จริงก่อนเทียบ
และจะล้มถ้าไม่ใช่เมื่อตั้ง `L110_REQUIRE_GNU=1` (CI ตั้งค่านี้)

## ยังไม่ได้ตัดสินใจ (รอเจ้าของโปรเจกต์)

- จะยกอ้างอิงไปเป็น Ubuntu LTS ที่ใหม่กว่า 24.04 เมื่อไหร่ ต้องตรวจก่อนว่า coreutils ของ release นั้นเป็น GNU หรือ
  ถูกแทนที่ด้วย implementation อื่นเป็นค่าเริ่มต้น (golden test จะจับกรณีนี้ได้) แล้วอัปเดตตารางนี้พร้อม CI
- เวอร์ชันของ util-linux / procps-ng / findutils / grep / sed / tar ล็อกเมื่อเริ่มทำคำสั่งของชุดนั้น (M3 เป็นต้นไป)
